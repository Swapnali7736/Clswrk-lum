What is HTML?

HTML stands for HyperText Markup Language. It is the standard markup language used to create and structure web pages. HTML tells the web browser how different elements such as headings, paragraphs, images, links, lists, tables, and forms should appear on a webpage.

What is CSS?

CSS stands for Cascading Style Sheets. It is a stylesheet language used to style and design web pages. CSS controls how HTML elements look on a webpage. CSS can be used to change colors, fonts, sizes, spacing, backgrounds, borders, and layouts. It also helps make websites responsive so that they can work properly on different screen sizes such as computers, tablets, and mobile phones.

What is Javascript?

JavaScript is a programming language used to make web pages interactive and dynamic. It allows websites to respond to user actions such as clicking buttons, entering information, submitting forms, and moving the mouse.

What is Bootstrap?

Bootstrap is a free and open-source CSS framework used to create responsive and attractive websites. It provides ready-made CSS classes and JavaScript components that make web development easier and faster.
